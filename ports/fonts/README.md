# Gotham Noir Dyslexia & Readability Font Stack

Gotham Noir pairs anti-halation contrast with high-legibility monospaced typography.

| Preset | Font Family | Best For |
| :--- | :--- | :--- |
| **Default** | `Monaspace Neon` + `Monaspace Radon` italics | Texture Healing (`+calt +ss01..03 +zero +cv10`) |
| **Wider Humanist** | `Monaspace Argon` + `Monaspace Radon` | Wider letter spacing for dyslexia comfort |
| **Low-Vision / Dyslexia** | `Intel One Mono` | Distinct `b/d/p/q` and `1/l/I` separation |
| **Maximum Homoglyph Clarity** | `Atkinson Hyperlegible Mono` | Braille Institute SIL OFL monospace |
| **Neutral Geometry** | `Commit Mono` | Ultra-neutral engineering proportions |

Ready-to-paste editor and Linux configs live in [`ports/ide-settings/font-presets.json`](../ide-settings/font-presets.json) and [`ports/linux-fontconfig/70-gotham-noir-fonts.conf`](../linux-fontconfig/70-gotham-noir-fonts.conf).
