# Gotham Noir for macOS Terminal.app

## One-Line Install (macOS)

```bash
curl -fsSL https://raw.githubusercontent.com/thezaynahmed/gotham-noir/main/ports/macos-terminal/apply-macos-terminal.sh | bash -s -- "Gotham Noir - Year One"
```

Variants: `Gotham Noir - Year One` (`year-one`), `Gotham Noir - Batcomputer` (`batcomputer`), `Gotham Noir - Arkham Slate` (`arkham-slate`), `Gotham Noir - Vengeance` (`vengeance`).
