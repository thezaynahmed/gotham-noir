# Gotham Noir Palette & CSS Tokens

- [`gotham-noir.css`](gotham-noir.css) and [`gotham.css`](gotham.css): CSS custom properties (`--gn-*`) for all 4 dark variants using `:root` and `[data-gotham-theme="batcomputer|arkham-slate|vengeance"]`.
- [`tokens.json`](tokens.json): W3C Design Tokens JSON with both sRGB hex and OKLCH values.
